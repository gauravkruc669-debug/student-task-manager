# Student Task Manager

A beginner-friendly technical project made with HTML, CSS and JavaScript.

## Features
- Add college/daily tasks
- Mark tasks as completed
- Delete tasks
- Shows total and completed task count
- Saves tasks in browser Local Storage
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript
- Local Storage

## How to run
Open `index.html` in any modern browser.

## Project description
Built a simple Student Task Manager to help students organize assignments and daily tasks. Implemented task creation, completion tracking, deletion, responsive styling, and browser Local Storage using basic JavaScript.
